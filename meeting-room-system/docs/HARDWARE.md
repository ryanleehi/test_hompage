# 하드웨어 배선

## 준비물 (회의실 1개당)

| 부품 | 비고 |
|---|---|
| ESP32-S3-CAM 보드 | Freenove ESP32-S3-WROOM CAM / ESP32-S3-EYE / XIAO ESP32S3 Sense 지원 |
| OV2640 카메라 모듈 | 보드에 딸려 오는 것 |
| PIR 센서 | HC-SR501 또는 AM312 |
| 5V 전원 | USB 어댑터 (500mA 이상) |

## PIR 연결

```
   HC-SR501 / AM312            ESP32-S3-CAM
  ┌──────────────┐           ┌──────────────┐
  │ VCC ─────────┼───────────┤ 5V  (AM312는 3.3V)
  │ OUT ─────────┼───────────┤ GPIO 21
  │ GND ─────────┼───────────┤ GND
  └──────────────┘           └──────────────┘
```

- **HC-SR501**: VCC는 5V. OUT은 3.3V 로직이라 S3에 바로 연결해도 됩니다.
- **AM312**: 3.3V 전용입니다. 5V에 물리면 망가집니다.
- 핀을 바꾸려면 `config.h` 의 `PIR_PIN` 만 고치면 됩니다.
  카메라와 PSRAM이 쓰는 핀은 피해야 합니다.
  (Freenove ESP32-S3 CAM 기준으로 남는 핀: **1, 2, 3, 14, 19, 20, 21, 38, 39, 40, 41, 42, 45, 46, 47, 48**)

## HC-SR501 조정

보드에 있는 가변저항 두 개와 점퍼를 회의실 용도에 맞게 맞춥니다.

| 항목 | 권장 |
|---|---|
| 감도(Sensitivity) | 중간~최대 (회의실 전체를 덮도록) |
| 지연시간(Time delay) | **최소** (가장 짧게) |
| 트리거 점퍼 | **H (반복 트리거)** |

지연시간을 기기에서 길게 잡을 필요가 없습니다.
"마지막 감지 후 몇 분까지 사용중으로 볼지"는 펌웨어의 `OCCUPANCY_HOLD_MS`(기본 2분)가 담당합니다.

## 설치 위치

- 카메라는 **출입문과 테이블이 함께 보이는 모서리 상단**이 좋습니다.
- PIR은 **에어컨 송풍구, 직사광선, 창문**을 피해야 합니다. 온도 변화로 오검출이 납니다.
- PIR 감지각은 보통 100~110도, 거리 5~7m 입니다. 큰 회의실은 사각지대가 생길 수 있으니
  센서 방향을 테이블 쪽으로 향하게 하세요.

## 보드별 카메라 핀맵

`camera_pins.h` 에 세 가지 프리셋이 들어 있습니다. `config.h` 상단에서 하나만 주석 해제하세요.

| 정의 | 보드 |
|---|---|
| `CAMERA_MODEL_FREENOVE_ESP32S3` | Freenove ESP32-S3-WROOM CAM (기본값) |
| `CAMERA_MODEL_ESP32S3_EYE` | Espressif ESP32-S3-EYE (핀맵 동일) |
| `CAMERA_MODEL_XIAO_ESP32S3` | Seeed XIAO ESP32S3 Sense |
| `CAMERA_MODEL_CUSTOM` | 직접 핀 정의 |

## 자주 겪는 문제

| 증상 | 확인할 것 |
|---|---|
| 부팅 시 `[CAM] 초기화 실패` | 보드 모델 선택, 카메라 FPC 케이블 방향/삽입 상태 |
| 영상이 끊기거나 재부팅 | 전원 부족. USB 어댑터를 500mA 이상으로 교체 |
| PSRAM 없이 동작 | Arduino IDE 보드 설정에서 PSRAM을 **OPI PSRAM** 으로 |
| PIR이 계속 사용중으로 표시 | 에어컨 바람/햇빛 확인, 감도를 낮추고 트리거를 H로 |
| PIR이 전혀 반응 없음 | `PIR_PIN` 번호, 5V/3.3V 전원, `PIR_ACTIVE_HIGH` 값 |
